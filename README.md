## C Learning Roadmap (Based on W3Schools Sidebar)

This project mirrors the C tutorial sidebar you showed (Intro, Variables, Loops, Pointers, etc.).  
For each topic, use the listed `.c` files in the `c` folder to revise and practice.

### 1. C HOME / Intro / Get Started
- **Goal**: Understand basic structure of a C program, compiling, and running.
- **Files to revise**:
  - `c/myfirstprogram.c`
  - `c/example1.c`

### 2. Syntax, Output, Comments
- **Goal**: Learn `#include`, `main`, `{}`, `;`, and printing output.
- **Files to revise**:
  - `c/myfirstprogram.c`
  - `c/example1.c`

### 3. Variables & Data Types
- **Goal**: Declare variables of different types and print them.
- **Files to revise**:
  - `c/variable.c`
  - `c/multivar.c`
  - `c/size.c`  (check sizes of each data type)

### 4. Constants, Assignment & Overwriting
- **Goal**: Understand assignment, updating values, and the idea of constants.
- **Files to revise**:
  - `c/assignment.c`
  - `c/overwriting.c`
  - `c/area.c` (using variables to calculate values)

### 5. Type Conversion & Decimal Precision
- **Goal**: Practice implicit/explicit casting and formatting decimals.
- **Files to revise**:
  - `c/type_conversion.c`
  - `c/DecimalPrecison.c`

### 6. Operators (Arithmetic, Comparison, Logical, Precedence)
- **Goal**: Use `+ - * / %`, comparison, logical operators, and understand precedence.
- **Files to revise**:
  - `c/operators.c`
  - `c/comparison.c`
  - `c/logical.c`
  - `c/precedence.c`

### 7. Booleans
- **Goal**: Use conditions that evaluate to true/false.
- **Files to revise**:
  - `c/bool.c`
  - Any `if` examples: `c/ifelse.c`, `c/nestedif.c`

### 8. If...Else / Nested If
- **Goal**: Control program flow with `if`, `else if`, `else`, and nested conditions.
- **Files to revise**:
  - `c/ifelse.c`
  - `c/nestedif.c`

### 9. Switch
- **Goal**: Replace long `if...else if` chains with `switch`.
- **Files to revise**:
  - `c/switch.c`

### 10. While Loop / Do...While Loop
- **Goal**: Repeat actions while a condition is true.
- **Files to revise**:
  - `c/loop.c`          (while loop)
  - `c/doloop.c`        (do...while)
  - `c/loopexample.c`

### 11. For Loop / Nested Loops
- **Goal**: Use `for` loops and loops inside loops.
- **Files to revise**:
  - `c/forloop.c`
  - `c/nestedloop.c`

### 12. Break / Continue
- **Goal**: Exit loops early with `break` or skip an iteration with `continue`.
- **Files to revise**:
  - `c/break.c`
  - Any loop files (`c/loop.c`, `c/forloop.c`) for practice adding `continue`.

### 13. Arrays
- **Goal**: Store multiple values of the same type and loop over them.
- **Files to revise**:
  - `c/arrays.c`
  - `c/arays` (folder, if you add more experiments)

### 14. Strings & String Functions
- **Goal**: Work with character arrays and common string functions.
- **Files to revise**:
  - `c/string.c`
  - `c/stringfunctions.c`

### 15. User Input
- **Goal**: Read values from the user safely using `scanf`.
- **Files to revise**:
  - `c/input.c`

### 16. Escape Sequences
- **Goal**: Use `\n`, `\t`, and other escape characters inside strings.
- **Files to revise**:
  - `c/escape.c`

### 17. Memory Address & Pointers
- **Goal**: Understand `&` (address-of), `*` (dereference), and pointer arithmetic.
- **Files to revise**:
  - `c/pointers.c`
  - Any array examples (`c/arrays.c`) to connect pointers and arrays.

### How to Use This for Revision
- **Step 1**: Pick a topic from the list (matching the W3Schools C sidebar).
- **Step 2**: Open the suggested `.c` files in the `c` folder.
- **Step 3**: Re-read the comments, predict the output, then compile and run.
- **Step 4**: Make small changes (different values, extra `printf`, more conditions) to test your understanding.

As you add new practice programs, update this `README.md` with the new filenames under the correct topic.
